# Порівняння ефективності алгоритмів

Програма для практичної роботи №9: емпіричний аналіз швидкодії трьох різних алгоритмічних підходів для знаходження 6-го за величиною елемента в масиві випадкових чисел.

## Що реалізовано

* **Генерація вибірки:** функція `generate_random_array(size)` для створення цілочисельних послідовностей у діапазоні `[-10 000; 10 000]`.
* **Досліджувані підходи:**
  1. `find_6th_by_sorting` — повне сортування масиву за спаданням ($O(n \log n)$) та взяття елемента за індексом 5.
  2. `find_6th_by_fixed_buffer` — підтримка відсортованого буфера з 6 найбільших елементів ($O(n)$).
  3. `find_6th_by_repeated_max` — шестикратний лінійний пошук максимального значення із заміною знайденого на мінімально можливе ($O(n)$).
* **Бенчмарк:** замір часу в мілісекундах (`ms`) з обчисленням середнього арифметичного за 3 запуски для формування звітної таблиці.

## Файл

* `task.py` — повна реалізація методів та цикл замірів
